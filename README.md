# Mobile Shop Management System - Demo & Proof of Concept

هذا المشروع عبارة عن **نموذج تجريبي (Demo / Proof of Concept)** لتوضيح الفكرة الأساسية وآلية عمل واجهات التطبيق لإدارة المتاجر وإصدار الفواتير.

> **تنبيه:** 
> الكود الموجود هنا يمثل جزءًا توضيحيًا فقط لعرض الفكرة والتصميم (Frontend / Core Logic). النظام الكامل والنسخة الفعلية المخصصة للاستخدام الإنتاجي تحتوي على كافة الخصائص، ربط قاعدة البيانات، ومعالجة البيانات بشكل كامل وآمن.

---

## 🎯 الغرض من المشروع (Purpose)
* عرض الفكرة الأساسية وتصميم الواجهات (UI/UX).
* توضيح آلية تنظيم وإدارة المبيعات والفواتير.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* HTML5 / CSS3
* JavaScript
